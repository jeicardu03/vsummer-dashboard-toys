ℹ️ Cómo se calcula el costo: cada bodega reporta su propio costo promedio, que puede variar entre sedes. Este dashboard reemplaza ese costo por el costo unificado de Análisis de Existencias Totales (el mismo para toda la compañía) en cada producto, y recalcula Valor Costo = Costo × Unidades — así el valor de cada bodega es comparable entre sí.
